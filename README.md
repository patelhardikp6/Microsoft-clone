# MICROSOFT-CLONE

A small static landing-page clone inspired by Microsoft's homepage. This repository contains the HTML and CSS used to render the page.

Files
- [project-2.html](project-2.html) — main HTML file (entry point).
- [project-2.css](project-2.css) — styles used by the page.
- [README.md](README.md) — this file.

Quick preview
- Open [project-2.html](project-2.html) in a browser.
- From VS Code use the Live Server extension or run a local server:

```sh
# from the project folder
python3 -m http.server 8000
# then open http://localhost:8000/project-2.html

Editing notes

-- HTML structure and classes are in project-2.html.
-- Visual rules are in project-2.css. Edit that file to change layout, colors, and responsiveness.
